3. 手机端完整流程与缩略图评审页。

推荐决定：

- 分享缩略图 1000×800、对比图 2400×1600；无需外部图像服务。
- 默认正常模拟延迟；评审设置可切换 0.5 秒和强制失败路径。
- 内存状态在服务重启后可丢失；同 requestId 的抽取始终不变，客户端可以重新提交恢复。
