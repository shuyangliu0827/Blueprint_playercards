# 第一批非视觉模块验收记录

验证环境：Node.js 24.19.0，Vitest 5.0.1，TypeScript 5.9.3。依赖已在本目录独立安装并写入锁文件。

最终执行 `npm run check`，配置检查、严格类型检查和全量测试全部通过：**9 个测试文件，199 项测试**。配置入口识别 1 个不可变概率版本与 18 个事件定义。

| 验收项 | 证据 |
| --- | --- |
| 常规抽取 | 10 万次固定测试种子：基础 39,868；银折 25,998；棱镜 18,125；金箔 10,976；黑曜 5,033 |
| 首抽保底 | 10 万次固定测试种子：基础 0；银折 43,191；棱镜 30,040；金箔 18,449；黑曜 8,320 |
| 分布检查 | 两个池均通过六倍标准差及卡方容差；只验证实现，不代表真实用户样本 |
| 幂等 | 完整请求号 HMAC；独立 OpenSSL 黄金结果；同请求重放；新版本加入后旧结果不变 |
| 边界 | 全零/最大 seed、各概率分界前后、数组重排、首抽原权重边界 |
| 配置失败 | 错档数、错总和、重复或未知档位、权重变化、旧文件指纹不符、字段缺失或额外字段均拒绝 |
| 启动失败 | 临时目录损坏各配置，执行真实检查命令，确认非零退出码；缺失密钥时无法构造发卡服务 |
| 跨平台与密钥边界 | 纯抽取打包为浏览器目标，在无 Node/DOM API 的隔离环境执行；服务端适配层拒绝客户端导入 |
| 输入 | 必填、同意、照片大小/清晰度边界、多人主体、号码前导零、昵称与禁用别名 |
| 姿势与故事 | 九个路由、独立镜像、非法枚举拒绝、模板 2–3 句和 80 字、无性别推断 |
| 统计口径 | 自动入册和分享面板不算保存；重试/修复不算再次生成；真实事件不因污染标记被剔除 |
| 事件边界 | 回流及 IP 聚合仅接受可信服务端调用边界；逐事件字段和类型校验；特殊匿名 ID 归因正确 |

详细抽样数值见 `distribution-results.json`。独立审阅发现的人脸字段、模板句数、事件夹带字段与特殊 ID 归因问题均已修复，并通过针对性复核。

## 尚未验收的部分

本批没有卡面、WebGL、分享物生成、真实人脸检测或 H5 流程，也没有运行 MockGenerator、重试返还任务、匿名 cookie/localStorage、加盐 IP 聚合或 Vercel 服务。相关接口、配置和事件是后续实现的输入，不能当作端到端功能已完成。

layout / effect 草案保持不变，设计师反馈不影响本批已验证模块。没有以模拟数据宣称第 10 节真实质量或传播门槛已达标。
